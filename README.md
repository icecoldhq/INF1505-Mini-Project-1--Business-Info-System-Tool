# INF1505-Business-Info-System-Tool

This is my submission for INF1505 Assessment 1. The project covers Chapters 1–3 and introduces a basic business information system. It is divided into two parts:
Mini-project for INF1505. This repo contains a markdown-based explanation and a basic info system design (Part 1), with a program implementation to follow (Part 2).


----

## 📘 Part 1 – System Explanation & Planning

This section includes written explanations of how a basic information system works, including:

- The role of user input
- How data is stored
- How data is categorized (TPS, MIS, etc.)
- What kind of reports are displayed
- A reflection on what I learned

There are two versions of the system explanation:

- **`explanation_original.md`** – My own original writing
- **`explanation_revised.md`** – A lightly revised version for clarity

Other files included:

- **Graphviz diagram PNG** showing system flow
- **Notebook file** that organizes the full explanation: `notebooks/system_explanation.ipynb`

---

## 💻 Part 2 – System Prototype (Code)

This part is a simple simulation of the information system using Python.

### 🔧 What it does:

- Lets a user enter business-related data (e.g., sales, customer info)
- Validates the input and stores it in a structured format
- Categorizes the data (TPS, MIS, etc.)
- Displays a basic summary report

### 📁 Folder: `/part2_program/`

Files include:

- `data_entry_system.py` – Python script version
- `data_entry_notebook.ipynb` – Jupyter Notebook version (more readable)
- `sample_data.json` – Optional example input data
