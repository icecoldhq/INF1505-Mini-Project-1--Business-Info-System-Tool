## 2. Step-by-Step Explanation

### a. User Input

The user enters data using an input device (like a keyboard) on a computer.

Before any data is handled, the organization needs to have clearly defined its goals, objectives, and success factors. This is important because the type of data being input depends on the organization's vision and what it wants to achieve.

Data can come from two sources: **internal** (inside the business) and **external** (from outside, like customers or suppliers).

**Validation check:**  
Cybercrime is a major issue for businesses. If an organization gets hacked, it could lose its data, face ransomware attacks, or suffer damage to its reputation — which could drive customers away.

That’s why the system uses a **validation check**. Data that fails the check is flagged and either corrected or rejected. Only data that passes validation is allowed to continue into the system for processing.

---

### b. Data Storage

Before data can be categorized, it needs to be processed into information.

The system stores this information using memory devices like secondary storage (e.g., the cloud), storage area networks (SAN), or network-attached storage (NAS). This ensures that data is kept safely and can be accessed when needed.

---

### c. Categorization

Data can be collected in different forms:

- **Aggregated data** — grouped into categories or summaries
    
- **Disaggregated data** — detailed and itemized information
    

Once the data is processed into information, the system categorizes it based on its purpose and use. For example, financial data from last year may help plan for the future, so it has **time orientation**.

The system then uses a basic program to decide what kind of information system the data belongs to:

- **TPS (Transaction Processing System):** Helps reduce costs by handling day-to-day transactions efficiently
    
- **MIS (Management Information System):** Turns data into useful information to support better decision-making
    

---

### d. Report Display

After processing and categorization, the system displays a report using an output device like a monitor or printer. The report shows summaries, totals, or useful business insights based on the input data.
